Vector databases store embeddings and support similarity search. FAISS is a library for efficient similarity search and clustering of dense vectors. It runs locally and is useful for prototypes and research. Qdrant adds persistent storage, filtering, APIs and operational features.
A production retrieval system should track document identifiers, source names, chunk identifiers, timestamps and access-control metadata. Metadata filtering prevents unauthorized chunks from entering a generation context. Index refresh and deletion workflows matter when source documents change.
Embedding models map text into vector representations. Query and document encoders must use compatible embedding spaces. Normalized vectors with inner product can implement cosine similarity. Choose embedding models by benchmarking on the target domain.
